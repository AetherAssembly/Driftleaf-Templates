# Driftleaf Vault Templates

Ready-made notes and folder layouts to help you get started with Driftleaf.
Choose a template, download its ZIP, and import it into your vault. You can
also browse or customize the files in this repository.

## Use a template

1. Browse the templates below and choose one that fits your needs.
2. Open the [latest release](https://github.com/AetherAssembly/Driftleaf-Templates/releases)
   and download the ZIP with the matching template name.
3. Import the ZIP into Driftleaf.

Each ZIP is named after its template folder, such as `meeting-notes.zip`. The
files inside are ready to go directly into your vault: any subfolders are
preserved, but the template folder itself is not added as an extra level.

## Templates included in Driftleaf

These templates are available as starter options when creating a vault:

- **Blank** — Start fresh. Driftleaf creates a `Welcome to Driftleaf` note.
- **General notes** — An inbox and project notes.
- **Productivity** — Tasks, a project list, and an archive.
- **Journal** — A dated journal entry starter. `{{date}}` is a date placeholder.
- **Study** — Course notes, an assignment tracker, and a study log.

The repository also contains the files for General notes, Productivity,
Journal, and Study. Blank is built into Driftleaf and does not have a ZIP.

## More templates

These templates offer additional starting points:

- **Daily Planner** — Daily focus and schedule.
- **D&D Campaign** — Campaign overview, sessions, locations, and NPCs.
- **Finance / Budget** — Monthly budget and transaction tracking.
- **Habit Tracker** — A daily habit log and review.
- **Knowledge Base** — An index and evergreen article starter.
- **Meal Planner** — Weekly meals and a grocery list.
- **Meeting Notes** — Agenda, discussion, decisions, and action items.
- **Period / Cycle Tracker** — A private, non-medical personal observation log.
- **Programming Project** — Project planning, implementation notes, decisions,
  and a release checklist.
- **Projects** — A project portfolio and project brief.
- **Recipe Book** — Recipe index and recipe card.
- **Task Management** — Task inbox, projects, and review workflow.
- **Travel Planner** — Itinerary, reservations, packing, and trip notes.
- **Work** — Priorities, responsibilities, and weekly reviews.

## Make it your own

To preview a template, open its folder in this repository. Copy or edit its
files to suit your workflow, or create your own template folder. Template files
can be Markdown, CSV, or JSON.

Pull requests are welcome! Automated checks validate supported file formats
and create a ZIP for each template folder, so we can spend less time on routine
checks. we manually review contributions for personal information before they
are included.
